## 設備の基本の知識
id: basics
確認日: 2026-10-14
- ガス給湯器（従来型）はガスの炎で使うときに沸かす。エコジョーズは排気の熱も使うガス給湯器で、ドレン水を流す配管が要る
- エコキュートは空気の熱で電気でお湯を沸かしてタンクにためる（エアコンの暖房と同じ原理）。タンクとヒートポンプの置き場所が要る
- ハイブリッド給湯器はヒートポンプで沸かしたお湯をためて使い、足りないときはガスで沸かす。エネファームはガスから取り出した水素で発電し、その熱でお湯をつくる
- 能力は、ガス給湯器は号数、エコキュートはタンクの容量で表す
- 給湯専用は追いだきができない。オート・フルオートは湯はりから追いだき・保温まで自動。給湯暖房（熱源機）は床暖房などへ温水も送る
- 交換は、同じ設置の形・号数・機能の機種への入れ替えが基本で、リモコンも替えることが多い。形を変えると配管や排気の工事が加わる
- ガスのにおいがしたら、火やスイッチに触れず、窓を開け、ガス栓を閉めて、ガス会社の緊急の窓口へ連絡する

## 当社の交換工事の進め方
id: flow
確認日: 2026-10-14
- ご相談 → 機種のご提案 → 現地調査（無料）→ お見積もり → ご契約 → 工事 → 試運転・お引き渡し
- 現地調査では配管・排気の向き・リモコンの線・搬入の経路を見る。エコジョーズはドレン水の流し先、エコキュートとハイブリッドは置き場所・基礎・電源も見る
- 見積書は本体・リモコン・標準工事・撤去と処分を分け、追加の工事は理由と金額を分けて書く
- 補助金を使うときは、契約時に共同事業実施規約を取り交わし、取り外す前と取り付けたあとに申請用の写真を撮る
- 工事の日は、外してから試運転が終わるまでお湯が使えない（時間は設置の形と機種で変わる）
- エコキュートには単相200Vの電源と専用のブレーカーが要り、ガスの配管を外すならガス会社への連絡が要る
- 賃貸の給湯器の交換は、貸主か管理会社が判断し費用を負担するのが通常

## 号数とお湯の量
id: gou
確認日: 2026-10-14
出典: https://rinnai.jp/products/waterheater/gas/about/power/
出典: https://www.noritz.co.jp/aftersupport/careful/summer_kyuto.html
- 号数は、水温より25℃高いお湯を1分間に何リットル出せるか。24号なら毎分24L。家庭用は24号・20号・16号が一般的
- リンナイの目安：4人家族は24号（3か所程度で同時に使う）、2人家族は20号、ひとり暮らしは16号（冬の水温5℃、40℃のシャワー毎分12Lと台所毎分5Lの条件）
- 冬は出せる量が減り、ノーリツの式では水温5℃で40℃を出すとき24号は毎分17.1L。24号でも1か所だけでは最大の能力を出し切れない（リンナイ）
- 実際の量は配管・水圧・シャワーヘッドで減ることがある。号数を上げるときはガスメーターの容量などが影響する（ノーリツ）
- 使うお湯の量が同じなら、ガスの使用量は号数で変わらない（リンナイ・ノーリツ）
- 入る水の温度のめやすは、夏 約25℃、春秋 約15℃、冬 約5℃（リンナイ）

## ふろの機能（給湯専用・オート・フルオート・給湯暖房）
id: bath-functions
確認日: 2026-10-14
出典: https://rinnai.jp/products/waterheater/gas/about/auto-full_auto/
出典: https://faq.noritz.co.jp/--64ba52e40a00fb001b38e1cf
- オートは湯はりから追いだき・保温まで自動。フルオートは、さらにたし湯（水位が約3cm下がると自動）と、栓を抜いたときの配管の洗浄（約5Lのお湯）まで自動（リンナイ）
- オートの「たし湯」スイッチでは、設定温度のお湯が約20Lたされる（リンナイ）
- ノーリツの「スタンダード」はフルオート、「シンプル」はオート。リンナイの型式では「A」がフルオート、「SA」がオート
- 冬に42℃のお湯に10分入ると、湯温が1℃以上下がる（リンナイ）
- 床暖房や浴室暖房乾燥機を使う家は給湯暖房（熱源機）が要る。暖房専用の熱源機を加える方法もある（リンナイ）
- 追いだきは浴槽と給湯器のあいだでお湯を循環させる。循環口の1つ穴・2つ穴で選ぶタイプが変わり、循環口が無ければその工事も要る

## 設置タイプ
id: install-types
確認日: 2026-10-14
出典: https://rinnai.jp/products/waterheater/gas/about/category/
出典: https://www.noritz.co.jp/product/kyutou_bath/gas/secchi.html
- 主な設置タイプは屋外壁掛・屋外据置・PS扉内設置・PS標準設置・アルコーブ設置・壁貫通・屋内設置で、置き場所と排気の向きで見分ける
- 屋外壁掛・屋外据置はそのまま替えやすく、パイプシャフトの給湯器は専用の取替え部材が要る。可否は現地調査で決まる（リンナイ）
- 形を変えると配管の延長や電源の工事が加わることがある。据置と壁掛に性能の違いは無い（ノーリツ）
- 燃焼の音と排気が隣家の寝室や居間に向くとトラブルになるおそれがある（ノーリツ）。アルコーブは排気カバーか排気延長タイプで玄関から離す
- 循環口が1つ穴なら設置フリータイプ（リンナイのRUF・ノーリツのGT）、2つ穴なら隣接設置タイプ。浴槽も替えるなら設置フリーが勧められる。バランス形ふろがまからは壁貫通タイプに替えられる場合がある
- リンナイの型式の末尾：Wは屋外壁掛型、Gは屋外据置型、TはPS扉内設置型・PS前排気型、Aはアルコーブ設置型

## エコジョーズとドレン排水
id: eco-jozu
確認日: 2026-10-14
出典: https://faq.rinnai.co.jp/faq/show/2431?site_domain=default
出典: https://www.city.yokohama.lg.jp/kurashi/machizukuri-kankyo/kasen-gesuido/gesuido/setsuzoku/haisui/youran.html
- 二次熱交換器で排気の熱を回収し、水を温めてから炎で沸かす（ノーリツ・リンナイ）
- ドレン水は酸性で、中和器で中和して流す。量は約60cc/分〜最大約100cc/分で冬に最も多い（リンナイ）
- ドレン水は下水道法上の汚水（リンナイ）。横浜市の排水設備要覧は汚水系統が原則で、JIA認証の機器なら雨水系統への排水も認めている。戸建ては雨どいや雨水ますへつなぐことが多い（このサイトの説明）
- 中和器は消耗品。ノーリツは10年程度に一度交換が要る場合があり、「92」で知らせ、「93」になると使えないとしている
- 寒い時期に排気口から出る白い煙は湯気で、エコジョーズは出やすい（リンナイ）

## エラー表示（メーカーの説明）
id: error-codes
確認日: 2026-10-14
出典: https://faq.rinnai.co.jp/category/show/279?site_domain=default
出典: https://www.noritz.co.jp/aftersupport/repair/
- 番号とメーカー・型番を控え、試すのはメーカーが案内する操作だけ。同じ番号でもメーカーで意味が違う（「12」はノーリツでは燃焼が途中で止まった表示、パロマの取扱説明書の例では給湯栓の絞りすぎ）
- パロマの取扱説明書：蛇口を閉め、運転を「切」にして5分ほど待って「入」にする。同じ番号が出たら点検・修理を頼む
- 「111」「11」は点火できなかった（ほかのガス機器も使えなければガスの供給を確かめる）。「14」「140」は過熱防止の安全装置の作動で、使うのをやめて修理を頼む（ノーリツ）
- 「290」は中和器やドレン排水のつまりで、冬はドレン配管の凍結でも出る。「562」はお湯はりの系統の不具合や配管の凍結・断水（リンナイ・ノーリツ）
- 「632」は浴槽の水が循環しない（循環アダプターより5cm以上の水・フィルター・凍結を見る）。「032」は排水栓の閉め忘れの検知で、追いだき配管の凍結でも出る（リンナイ・ノーリツ）
- 「920」は中和器の寿命の予告で、1〜2か月は使えるが「930」になると使えない。「900」は給・排気の閉塞で、雪などでふさがれていないかを見る（リンナイ）
- 震度5以上の地震のあとはガスメーターがガスを止めることがある（ノーリツ）。台風や豪雨の湿気で「111」「12」が出たら、落ち着いてから操作し直す（リンナイ）

## 凍結の予防と対処
id: freeze
確認日: 2026-10-14
出典: https://rinnai.jp/products/waterheater/freeze/
出典: https://www.noritz.co.jp/aftersupport/disaster/cold_wave.html
- お湯と水は別の配管で、水が出てもお湯の配管が凍っていることがある（ノーリツ）
- 自然に解けるのを待つのが基本（日陰では数日かかることも）。熱湯はかけない。電源プラグは抜かない（凍結予防が働かなくなる）
- ノーリツの応急処置：運転を切り、お湯側の蛇口を少し開け、ガス栓を閉め、給水元栓にタオルを巻いて30〜40℃のぬるま湯をゆっくりかける
- 予防：電源プラグは差したまま（まわりが約3℃以下で凍結予防が働く）。浴槽に循環口より5cm以上の残り湯を残す。冷え込む夜は、お湯側の蛇口から1分間に約400mL（太さ約4mm）の水を流す（リンナイ）
- 凍結予防は本体を守るが、つながる配管までは防げない。保温材が切れて金属が見える所は凍りやすい（ノーリツ・リンナイ）
- 長く留守にするとき・停電や断水のときは、取扱説明書の手順で水抜きをする。凍結による破損は保証期間内でも有料（リンナイ・ノーリツ）
- 雪で排気口がふさがれたまま使うと、不完全燃焼の原因になる（ノーリツ）

## 給湯器の音
id: noise
確認日: 2026-10-14
出典: https://faq.noritz.co.jp/--64ba5c5ccbfec4001b1d8332
- 本体から「ピー」「ブーン」と鳴るのは燃焼の不具合の可能性（ノーリツ）。お湯を止めたときの「カーン」は配管のウォーターハンマー現象（リンナイ・ノーリツ）

## 水漏れと正常な排水
id: leak
確認日: 2026-10-14
出典: https://faq.noritz.co.jp/--655ad9c754d634001c238778
- 本体の箱から漏れる・使っていないのに水抜き栓から出続けるときは、水を止めて連絡する（ノーリツ）
- 正常な水：エコジョーズのドレン水と、使ったあと水抜き栓から落ちる水滴。配管からの漏れは配管の破損が考えられ、施工した販売店や配管業者へ（ノーリツ）
- 止め方：蛇口を閉め、リモコンを「切」、給水元栓（「水」の目印）とガス栓（「ガス」の目印）を閉める
