# 商品データの作り方と、確かめた範囲

調べた日：2026-10-14。データは `data/products/<メーカー>.ts`、型は `data/products/types.ts`、画面への出し方は `lib/products.ts`。

## 1. 掲載している機種（67機種）

| メーカー | エコジョーズ | 従来型 | ハイブリッド | エコキュート | 計 |
| --- | ---: | ---: | ---: | ---: | ---: |
| リンナイ | 9 | 0 | 7（ECO ONE） | — | 16 |
| ノーリツ | 9 | 2 | 6（HPHB R290） | — | 17 |
| パロマ | 7 | 2 | 5（HYBRID PLUS） | — | 14 |
| 三菱電機 | — | — | — | 5 | 5 |
| パナソニック | — | — | — | 5 | 5 |
| ダイキン | — | — | — | 5 | 5 |
| コロナ | — | — | — | 5 | 5 |

- 型番・仕様は、各メーカーの公式サイトの製品ページ・総合カタログ（PDF）・製品データのサービスで確かめた。機種ごとの根拠の URL は `sources`。
- 架空の型番は1つもない。調べた資料の中で型番を見つけられなかったものは載せていない。
- 販売の状態が「現行品」と確かめられたものだけを載せている（`availableStatus: "current"`）。

### 載せなかったもの（理由）

- リンナイの従来型 RUF-A2405SAW(C)・RUX-A2015W(A)-E：カタログで「集合住宅特定現場向け」の区分にあり、一般の交換で選べる機種かを確かめられない。
- リンナイ ECO ONE の集合住宅専用モデル（新築向け）と、屋内設置タイプ（寒冷地向け）：交換工事の機種として合わない。
- リンナイ ECO ONE は、同じ熱源機が複数のシリーズに出てくるため、シリーズごとに標準モデルの構成（熱源機＋ヒートポンプ＋タンク）だけを載せた。型番はユニットを「 + 」でつないだ形、URL は全ユニットの型番をつないだ形。
- ノーリツの「ユコア」4機種：現行品かどうかを確かめられなかった。
- エコキュートは、一般地向け（横浜市は一般地）の機種だけ。寒冷地仕様・耐塩害仕様の別型番は、仕様の注記に書いた。

## 2. 価格

- **当社の価格**（`salesPrice`・`remotePrice`・`installationPrice`・`disposalPrice`）は、会社から金額を受け取るまで `null`。画面では「お見積もり」と出す。4つがそろったときだけ、合計（税込）を出す。
- **メーカー希望小売価格**（`manufacturerPrice`）は、メーカーが「希望小売価格」と書いているものだけ。含むもの（本体だけか、リモコン・ユニットを含むか）を `includes` に書き、画面にも出す。2026年9月の価格改定のあとの価格。
  - 三菱電機・パナソニック・ダイキンのエコキュートは、公表されている価格が事業者向けの積算の価格で、希望小売価格ではないため、載せていない（画面では「公表していません」）。
- ほかの販売店の価格は、一切使っていない。
- 部品やリモコンの価格は、当社の価格と紛らわしいため、表示する文から外した。

## 3. 補助金（給湯省エネ2026事業）

- ガス給湯器・エコジョーズは「対象外」（`not-target`）。
- エコキュート・ハイブリッド給湯器は、国の「補助対象製品の検索」で型番ごとに登録を確かめ、`subsidyListedModel`（登録の型番）・`subsidyEligibility`（`eligible`＝基本額のみ／`bonus`＝性能加算も）・`subsidyAmount` を入れた。
  - ハイブリッド給湯器は、ヒートポンプユニットの型番で登録されている。年間給湯効率の登録値は、仕様の欄に「国の対象製品リストの登録値」として載せた。
  - リストの注記（〇1：本体のみ／〇2：台所リモコン・貯湯ユニットとの組み合わせ など）は `subsidyNote` に書いた。
- 額は `data/subsidy/programs.ts` から計算した値と一致することを `npm run data:check` が確かめる。
- 登録がいまも続いているかは `npm run subsidy:check` が国の検索で確かめる（2026-10-14 は32型番すべて登録あり）。

## 4. 写真

製品写真は載せていない（メーカーの許諾を確かめていないため）。くわしくは `docs/IMAGE_SOURCES.md`。

## 5. データを足す・直すとき

1. メーカーの公式ページ・カタログで、型番・仕様・希望小売価格・販売の状態を確かめる。
2. `data/products/<メーカー>.ts` に足す（`slug` は型番を英小文字とハイフンにしたもの。公開後は変えない）。
3. ハイブリッド給湯器・エコキュートは、国の「補助対象製品の検索」で登録を確かめる。エコキュートの型番検索は `Model_number?search=型番` だけで引く（`option=1` を付けると0件になる）。
4. 表示する文（特徴・注意・仕様）には、調べたときのメモ書き（「カタログの表記は…」「未確認」など）を残さない。部品の価格も書かない。
5. `npm run data:check` → `npm run build` → `npm run site:check`。
