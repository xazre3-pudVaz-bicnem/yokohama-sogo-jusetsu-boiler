# 商品データの作り方と、確かめた範囲

調べた日：2026-10-14（2026-11-16・17 に22機種を追加）。データは `data/products/<メーカー>.ts`、型は `data/products/types.ts`、画面への出し方は `lib/products.ts`。

- 型番・仕様は、各メーカーの公式サイトの製品ページ・総合カタログ（PDF）・製品データのサービスで確かめた。機種ごとの根拠の URL は `sources`。
- 架空の型番は1つもない。調べた資料の中で型番を見つけられなかったものは載せていない。
- 販売の状態が「現行品」と確かめられたものだけを載せている（`availableStatus: "current"`）。
- 2026-11-16・17 の追加：リンナイのエコジョーズ10機種（RUF-E・RUX-E・RUFH-E・RUF-TE。2026年9月改定の希望小売価格）、ノーリツの従来型6機種（GT-70シリーズ4機種・GQ-79WS 2機種）、パロマの従来型6機種（FH-23シリーズ4機種・PH-2017AW・PH-2427AW）。
  - ノーリツの6機種の仕様は、公式カタログ（総合カタログ2026.Ⅲ）で確かめられた値だけ（ガス消費量・消費電力・熱効率・質量・モード熱効率）。カタログの型番と価格の数字は埋め込みの符号の文字のため、ページを画像にして目で読み、税込＝税抜×1.1 を確かめた。
  - 製品データサービス（n-techdocs.com）は robots.txt で自動の取得を断っているため、今回の追加では使っていない（2026-10-14 の掲載分の写真・出典には、このサービスのものが残っている）。
  - パロマ FH-2023SAW-1 の消費電力は、公式カタログの仕様表（壁掛型の行）に合わせて 100W に直した（製品ページの表は 115W）。

### 載せなかったもの（理由）

- リンナイの従来型 RUF-A2405SAW(C)・RUX-A2015W(A)-E：カタログで「集合住宅特定現場向け」の区分にあり、一般の交換で選べる機種かを確かめられない。
- リンナイ ECO ONE の集合住宅専用モデル（新築向け）と、屋内設置タイプ（寒冷地向け）：交換工事の機種として合わない。
- リンナイ ECO ONE は、同じ熱源機が複数のシリーズに出てくるため、シリーズごとに標準モデルの構成（熱源機＋ヒートポンプ＋タンク）だけを載せた。型番はユニットを「 + 」でつないだ形、URL は全ユニットの型番をつないだ形。
- ノーリツの「ユコア」4機種：現行品かどうかを確かめられなかった。
- パロマ PH-2426AW・PH-2015AW：カタログで「在庫限り」。後継の PH-2427AW・PH-2017AW を載せた。
- 同じ機種の L 付き・BL 付きの別型番（パロマ FH-2423SAWL-1 など、ノーリツ GQ-2479WS BL など）：本体の仕様が同じため、片方だけを載せた。
- リンナイの総合商品情報サイト（rkids.rinnai.jp）・ノーリツの業者向けサイト（oyunet）・パロマの会員向けサイト（ほっとなび）は、接続認証・会員向けのため使っていない。
- エコキュートは、一般地向け（横浜市は一般地）の機種だけ。寒冷地仕様・耐塩害仕様の別型番は、仕様の注記に書いた。

## 2. 古い型番と後継機種（`data/products/successors.ts`）

- メーカーが公式の資料で示している対応だけ（リンナイ・ノーリツの取り替えの表、三菱電機・パナソニックの後継機種の一覧、ダイキンの DT-NET の後継モデル、リンナイのモデルチェンジのリリース）。295行・古い型番 1,020件（2026-11-16 に確かめた）。
- 載せていないもの：従来品との比較だけの記述、シリーズ単位の記述、コロナ（後継の機種がすでに生産終了）、パロマの取替表、ノーリツの商品欄の中の取り替え推奨品の注記（型番の文字が埋め込みの符号で、欄を確かめきれない）。
- 画面は `/products/successor`（入口）と `/products/successor/<メーカー>`（一覧）、機種のページの「前のモデルから」。`npm run data:check` が出典のドメイン・重なりを確かめる。

## 3. 価格

- **当社の価格**（`salesPrice`・`remotePrice`・`installationPrice`・`disposalPrice`）は、会社から金額を受け取るまで `null`。画面では「お見積もり」と出す。4つがそろったときだけ、合計（税込）を出す。
- **メーカー希望小売価格**（`manufacturerPrice`）は、メーカーが「希望小売価格」と書いているものだけ。含むもの（本体だけか、リモコン・ユニットを含むか）を `includes` に書き、画面にも出す。2026年9月の価格改定のあとの価格。
  - 三菱電機・パナソニック・ダイキンのエコキュートは、公表されている価格が事業者向けの積算の価格で、希望小売価格ではないため、載せていない（画面では「公表していません」）。
- ほかの販売店の価格は、一切使っていない。
- 部品やリモコンの価格は、当社の価格と紛らわしいため、表示する文から外した。

## 4. 補助金（給湯省エネ2026事業）

- ガス給湯器・エコジョーズは「対象外」（`not-target`）。
- エコキュート・ハイブリッド給湯器は、国の「補助対象製品の検索」で型番ごとに登録を確かめ、`subsidyListedModel`（登録の型番）・`subsidyEligibility`（`eligible`＝基本額のみ／`bonus`＝性能加算も）・`subsidyAmount` を入れた。
  - ハイブリッド給湯器は、ヒートポンプユニットの型番で登録されている。年間給湯効率の登録値は、仕様の欄に「国の対象製品リストの登録値」として載せた。
  - リストの注記（〇1：本体のみ／〇2：台所リモコン・貯湯ユニットとの組み合わせ など）は `subsidyNote` に書いた。
- 額は `data/subsidy/programs.ts` から計算した値と一致することを `npm run data:check` が確かめる。
- 登録がいまも続いているかは `npm run subsidy:check` が国の検索で確かめる（2026-10-14 は32型番すべて登録あり）。

## 5. 写真とロゴ

- 製品写真は、メーカーの公式サイト・公式資料の写真（2026-10-15 に、依頼者からメーカーの使用許可の取得済みの連絡を受けて掲載）。
- 写真の記録は `data/products/images.json` の1か所（メーカー別の `<メーカー>.ts` には書かない）。一覧・機種のページ・比較・トップは、どれも `data/products/index.ts` がこの記録から足した `images` を使う。
- 型番との対応は `matchType`（`exact-model`＝その型番の写真／`officially-shared-series`＝メーカーが同じシリーズの型番に共通で使っている写真／`unavailable`＝外観の合う公式の写真が無い）。似た機種の写真で埋めない。
- 全機種の一覧は `docs/PRODUCT_IMAGE_AUDIT.md`（`npm run images:check -- --write` で作り直す）。手順と決まりは `docs/IMAGE_SOURCES.md`。
- メーカーのロゴは `public/images/manufacturers/`、記録は `data/brand-logos.json`。

## 6. データを足す・直すとき

1. メーカーの公式ページ・カタログで、型番・仕様・希望小売価格・販売の状態を確かめる。
2. `data/products/<メーカー>.ts` に足す（`slug` は型番を英小文字とハイフンにしたもの。公開後は変えない）。
3. ハイブリッド給湯器・エコキュートは、国の「補助対象製品の検索」で登録を確かめる。エコキュートの型番検索は `Model_number?search=型番` だけで引く（`option=1` を付けると0件になる）。
4. 表示する文（特徴・注意・仕様）には、調べたときのメモ書き（「カタログの表記は…」「未確認」など）を残さない。部品の価格も書かない。
5. 写真を足す・替えるときは `docs/IMAGE_SOURCES.md` の手順で記録を作り、`npm run images:apply -- <記録のフォルダ>` → `npm run images:check`。
6. `npm run data:check` → `npm run build` → `npm run site:check`。
