## 2. 製品写真

**どのメーカーも、公式サイトの写真を許諾なしに転載することを禁じています。**
そのため、製品写真は1枚も載せていません。機種のページとカードには、設置の形を表す図（コードで描いたもの。`components/diagram/TypeFigure.tsx`）を出し、「製品写真は準備中」と添えています。
AI で生成した画像や、ほかの販売店のサイトの写真は使いません。

各機種のデータには、写真があった場所（`imageSource.url`・`pageUrl`）と確認日を記録しています（`imageLicenseStatus: "pending"`）。

### パナソニックの「画像データ ダウンロード」の条件（要約）

1. 当社が代理店等から仕入れて、自社の顧客に再販している、パナソニック商品の広告宣伝にだけ使う
2. 画像を改変しない（トリミング・文字のせが改変に当たるかは書かれていないので、迷う加工はしない）
3. 掲載以外の複製・譲渡・送信・使用許諾をしない
4. パナソニックの商品だと分かる表示（会社名・商品名）をする。商標のロゴや、関係を誤認させる表示はしない
5. 設置例の写真を、自社の施工事例のように見せない
6. 人物のモデル写真は、書面の承諾なしに使わない
7. パナソニックから指示があれば従う

## 3. 許諾が取れたときの手順

1. 許諾の内容（誰が・いつ・どの範囲で）を、この表と `data/brands.ts` の `imagePolicy` に書く（`status: "permitted"`）。
2. 機種の `imageSource.url` を、許諾された画像の URL にし、`imageLicenseStatus` を `"permitted"` にする。
3. `npm run images:products` で取り込み、表示された `images` の内容を、機種のデータに足す。
4. `npm run data:check` で、許諾と写真の組み合わせを確かめる。

## 4. 当社の写真を足すとき

- トップの写真は、当社が施工した給湯器の写真に差し替えるのがいちばんです。`public/images/photos/` に置き、`npm run images:prepare`。
- 施工事例の写真は、お客様の了承を得たものだけ。表札・車のナンバー・近所の家が写らないように。手順は README の「施工事例を足す」。
